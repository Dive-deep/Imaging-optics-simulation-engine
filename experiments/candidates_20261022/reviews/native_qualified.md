# 고 NA 후보의 독립 원본 엔진 대조

`results/qualified_round1`에서 다음 조건을 모두 만족하는38개 처방을 고정하여
원본 v0.2.1 Python 엔진과 후보 탐색용 C 커널을 독립 대조했다.

- `all_declared_numeric_constraints_and_sampled_rays_passed=true`.
- RGB 각각 축상 완전 통과 rim의 보수적 NA가0.7 이상.
- aperture-fit 단계에서 원래 통과 광선 수와 전체 표본 수가 동일.

이 선택 조건은 기존 전체표본 평가 결과를 이용했지만, 아래 교점·Snell·OPL은
저장된 성능값을 읽어 합격으로 인정하지 않고 원본 `trace_ray`로 새로 계산했다.
계산된 실제 처방의 곡률·conic·A4…A12와 매질 순서로 원본 `Surface`,
`OpticalSystem`, `Material`을 별도로 구성했다. 굴절률은 동일한 사용자 nd/Vd와
채택된 normal-line 모델의486/588/656nm 값을 사용했다. 이 검사는 재료 분산
근사의 실측 정확도나 Zemax 일치 검증은 아니다.

각 처방에서 RGB3파장 × 0/0.5/0.8/1F × pupil25점을 추적했다. Pupil 표본은
16rings×48arms 원래 표본에서 chief1개, 반경이 다른 내부 ring2개에서8방위각씩,
rim8방위각을 택한 것이다. 총 **11,400개 광선**, 각 광선의6개 굴절 경계면을
비교했다. 모든 표본 인덱스·정규화 좌표와 입력/소스 SHA256은
`results/native_qualified38/plan.json`에 있다.

| 처방 수 | 38 |
| 새로 추적한 광선 수 | 11,400 |
| 원본/네이티브 상태 또는 수치 허용치 실패 | 0 |
| 최대 경계면 위치 차이 | 3.39515e−11mm |

원본 엔진과 C 커널 모두 가장 먼저 만나는 전방의 실제 sag 교점을 선택한다.
고차 비구면의 다른 교점으로 건너뛴 표본은 발견되지 않았다. 위치·OPL은
절대1e−8mm, 방향은 절대2e−10을 대조 한계로 사용했으며 관측 최대치는
그보다 작았다. 모든 표본을 유지했고 실패한 광선을 제외하여 계산한 비교는 없다.

또한 원본 `validate_geometry`의 방사 구간 검사를 모든 처방에 적용했다.
이는101/1025개 점만 확인한 기존 sampled 검사에 추가한 근거이며, 모든
인접면의 **공통 clear radius 영역**에서 conic-domain과 면 교차 여부를 검사한다.
원본 알고리즘은 부동소수점 구간 경계를 사용하는 수치 검사이며 형식 검증된
임의 계수 증명은 아니다. 서로 다른 앞·뒤 clear radius 밖의 기계적 렌즈 외형,
edge/chamfer, 가공 여유 또는 전체 기구 간섭을 인증하지 않는다.

이 대조는 선택된 광선의 실광선 결과가 원본과 일치한다는 검증이다. 모든
연속 pupil/field의 전역 극값, PSF/FFT MTF 수렴, 고 NA 벡터 회절 또는 광학
성능의 전역 최적성을 증명하지 않는다. 현재 후보의 화질이 우수하다는 판단도
이 결과만으로 할 수 없다. 최종24개를 여기서 선택할 때 실제 처방이 바뀌지
않았다면 입력 hash 연결로 근거를 재사용할 수 있으며, 변경된 처방은 다시
수치 검증해야 한다.

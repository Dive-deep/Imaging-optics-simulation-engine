# CT20 후보군 보고서 검토

2026-10-22. 새 실험의 최종 후보 23개를 대상으로 보고서 생성과 데이터·브라우저 검증을 완료했다. 이전 `candidates_20261022` 실험은 수정하지 않았다.

## 후보군 보존과 CT 조건

- 합격한 독립 parent 23개를 모두 보존했다. 동일 parent의 여러 checkpoint 중 하나만 기하 screening 점수로 선택하며, 서로 다른 후보의 전체 성능 순위는 만들지 않는다.
- `CT20_XXXX`는 원본 seed에서 생성한 고정 ID다. 최종 표·그림 순서는 유리 위치, 재료 순서, 원본 seed ID다.
- 실제 처방의 각 중심 두께를 `2 < CT <= 20`으로 검사하고, 새 하한·상한 metric gate 및 모든 기하·광선 판정이 통과해야 생성·최종화·렌더 단계로 진행한다. CT의 양의 초과 허용 오차를 추가하지 않았다.
- 이력은 기존 출발점에서 `ct20_continuation`, `ct20_polish`, `ct20_rescue`, `ct20_stop_scan` 및 `parent_input.source_result`까지 연결한다. STOP 스캔으로 회복한 두 후보의 원래 반경·변경량과 방법 태그가 최종 자료에 들어 있다.

## 실제 출력과 표시 범위

`reports/candidate_layouts_and_mtf.pdf`는 23페이지이며 `plots/`에 같은 23개 후보의 개별 그림이 있다. `candidate_contact_sheet.png`는 모든 단면을 한 그림에 표시한다. `candidate_report.html`은 전체 단면을 첫 화면으로 열며, 초기 상태에 특정 후보를 선택하거나 강조하지 않는다. 전체 데이터와 이미지가 내장되어 있다.

각 후보에는 588 nm 실제 광선 단면, chief·양쪽 marginal, 면별 처방 표, RGB spot 0.5F/1F, RI·왜곡, 0/0.5/0.8/1F의 0–20 lp/mm T/S 곡선이 있다. 서로 다른 앞·뒤 clear semi-diameter를 반영하며 광학 clear 끝점의 연결은 기구 외곽 인증이 아닌 개략도다. 실패 광선은 마지막으로 계산된 위치에서 끝내고 상면으로 연장하지 않는다.

총 92개 field 패널 중 64개는 저장된 scalar 파동 곡선, 28개는 명시적인 기하 MTF 진단 패널이다. 어느 RGB 파장의 scalar 곡선이 없으면 해당 패널 전체를 기하 진단으로 표시하여 서로 다른 모델을 같은 패널에서 섞지 않는다. 276개 RGB T/S 쌍과 RGB 합성 곡선을 제공한다. Scalar pupil autocorrelation과 실제 FFT 진단을 구분하며 미수렴·적용 불가 상태를 보존한다. 기하 MTF를 회절 MTF나 0.5% 정확도 인증으로 해석하지 않는다.

표제와 HTML 지표에는 588 nm 및 spot RMS 반경을 명시한다. Spot 그림은 공통 RGB centroid에 대한 가독성용 8×24 표본이고, 숫자는 저장된 전체 표본의 계산값이다. RI는 무코팅 Fresnel·chief-map 근사다. 각 후보의 CT 세 값도 별도로 표시한다.

## 집계 오류 수정

기존 최종화 코드에서 4-field metric 광선 수를 13-field 이름으로 표기하던 오류를 수정했다. 현재 두 집계는 분리되어 있다.

| 범위 | 후보당 RGB 광선 수 | 근거 |
|---|---:|---|
| 4-field 성능 metric | 9,804 | `metrics.all_requested_native_status_counts` |
| 13-field aperture-fit | 31,863 | `aperture_fit.sampled_ray_count` |

최종화 재실행 전후 METHOD의 §1–9 본문이 동일함을 검사했다. 자동 생성 §10에는 STOP 스캔 설명과 해당 두 후보의 방법 태그를 추가했다. 이후 root가 작성한 독립 검증 문단은 이 검사의 대상과 별개다.

## 검증 결과

- `results/report_content_qa.json`: 후보·PDF 페이지·개별 PNG 각각 23개, 92개 패널, RGB 276쌍 확인. 모든 ID·내장 원자료를 보존하고 RI·spot·CT 요약값이 원자료와 정확히 일치한다. 모든 실제 CT와 metric gate가 통과했다.
- 최종 `CT20_0025`와 `CT20_0059` 페이지를 시각 검토했다. 각각 엄격한 EPD50 모드와 첫 렌즈 지름50 모드이며, scalar와 기하 진단의 서로 다른 표시를 확인했다. 전체 23개 단면 그림도 검토했다.
- `results/report_browser_qa.json`: 실제 최종 HTML에서 전체 후보 첫 화면, 처음·마지막 후보 이동, 전체 보기 복귀, 원본 seed 검색, STOP 이력 포함 후보 JSON 다운로드, 빈 검색의 제어 비활성화가 통과했다. 구경 필터는 EPD50 1개와 첫 렌즈 지름50 22개를 표시한다.
- 브라우저 JavaScript 오류 0건, 외부 네트워크 요청 0건. HTML 내장 record·summary·image와 고유 ID가 각각 23개다.
- 데스크톱 1440×1100 및 모바일 430×900에서 전체 보기·개별 후보 화면을 모두 캡처하고 검토했다. 화면 밖 잘림 없이 제어·지표가 재배치된다. 모바일의 과학 그림은 화면 폭에 맞춰 축소되므로 세부 곡선을 읽으려면 확대하거나 PDF를 이용해야 한다.

관리 브라우저의 `file://` 탐색 제한 때문에 정확한 최종 HTML을 Playwright `page.setContent`로 로드해 검증했다. 브라우저 정책을 변경하지 않았다. 이는 오프라인 문서의 실제 렌더링·JavaScript 동작 검증이며, 사용자의 로컬 파일 열기는 해당 브라우저 정책에 따른다.

추가 코드 제어에서는 30개 parent를 최소 개수 24로 요청해도 전부 보존됨을 확인했고, CT 경계 12개와 상한 gate 누락을 검사했다. 별도 읽기 전용 소프트웨어 검토에서 제안된 기하 fallback 배열 검증도 반영했다. 유한성·배열 길이·DC·주파수 범위/순서를 검사하며 잘못된 배열 5종을 거부했다. 이 합성 계약 제어를 광학 정확도나 최종 처방의 물리 검증으로 재사용하지 않았다.

최종 주요 파일 크기는 HTML 26,457,313 bytes, PDF 1,448,977 bytes, 전체 단면 PNG 1,898,606 bytes다. 이 보고서는 후속 설계 탐색용 후보군 전체를 보여주며 전역 최적, 제조 적합성, 전 시야 고MTF 달성 또는 Zemax 수치 동치를 주장하지 않는다.
